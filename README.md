# 📸 Image Accordion Component

A clean and interactive **Image Accordion UI component** built using HTML, CSS, and . When you hover over an image, it expands smoothly while the other images shrink, creating a modern accordion-style gallery.

---

## 🚀 Features
- Smooth hover animation
- Fully responsive layout
- Lightweight and fast
- Pure HTML, CSS & JavaScript (no external libraries)
- Easy to customize (images, size, animation)

---

## 🛠️ Technologies Used
- **HTML**
- **CSS** (Flexbox, transitions)


---





## 📸 How It Works
- The container holds multiple images.
- When the user hovers over an image, its width increases.
- CSS transition creates the smooth accordion effect.
- JavaScript can be used for extra interactions (optional).

---

## 💻 How to Use
1. Clone or download this repository.
2. Replace the images inside the **images** folder with your own.
3. Update image paths in the HTML file if needed.
4. Open `index.html` in your browser.
